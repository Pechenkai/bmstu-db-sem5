# Лабораторные работы по базам данных

Тема базы данных — зоопарк: в базе используются таблицы вольеров, животных, сотрудников и записей об уходе.

## Лабораторные работы

| Каталог | Содержание |
| --- | --- |
| `lab_01` | Генерация тестовых данных с помощью Faker. |
| `lab_02` | SQL-запросы: выборки, подзапросы, агрегаты, CTE, оконные функции и изменение данных. |
| `lab_03` | Пользовательские функции, процедуры, курсоры и триггеры PostgreSQL. |
| `lab_04` | Расширенные объекты PostgreSQL: агрегатные и табличные функции, процедуры, триггеры и типы. |
| `lab_05` | Работа с JSON/JSONB в PostgreSQL. |
| `lab_06` | Консольное приложение Python с запросами к PostgreSQL через `psycopg2`. |
| `lab_07` | ORM и JSON в Python: SQLAlchemy, запросы к объектам и SQL. |
| `lab_08` | Обработка данных в Python. |
| `lab_09` | Сравнение операций PostgreSQL и Redis; графики времени выполнения. |
| `db_create` | Скрипты создания, заполнения, ограничения и удаления основной схемы. |
| `rk3` | Рубежный контроль: SQL-запросы и ORM Peewee для предметной области спутников. |
